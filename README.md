# TodoList

## Технологии

- Swift
- VIPER
- SwiftUI
- Async/Await
- SwiftyJSON
- CoreData
- UnitTest

## Реализованные функции:

- Приложение показывает список задач, которые могут быть в состояниях: выполнено и не выполнено. В футере указано количество задач. Задачи можно создавать, удалять, редактировать.
- Добавлен поиск с debounce (выполняется через несколько секунд после окончания ввода пользователя), который фильтрует задачи по названию или описанию.
- Добавлен функционал записи и распознавания речи при нажатии на кнопку "микрофон", распознанный текст отображается в поле поиска, затем срабатывает сам поиск.
- Добавлены действия реагирования на движения по Задаче: свайпы (влево, вправо), долгое нажатие, нормальное нажатие. На долгое нажатие отображается контекстное меню, свайп вправо - добавить или убрать чек задачи, свайп влево - удаление задачи.
- При первом запуске приложения происходит загрузка стартовых задач из json файла по url. Затем при добавлении, редактировании или удалении задачи происходит их сохранение в БД.
- При свайпе вниз всего списка задач происходит обновление списка
- Реализована некоторая часть тестов: загрузка, добавление, редактирвоание, удаление, тогл выполнения задач.
